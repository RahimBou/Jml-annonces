# JML Studio — première version
Module autonome de création graphique intégré à JML Annonce.
- URL : /studio.html
- Éditeur Canvas natif, sans dépendance graphique serveur.
- Formats : carré, portrait, story et paysage.
- Ajout d'images, textes, formes, déplacement et redimensionnement.
- Modèles de départ, pages multiples et sauvegarde locale IndexedDB.
- Export PNG d'une page ; double-clic sur Exporter PNG pour exporter les pages en ZIP.
- Les projets restent dans le navigateur utilisé : pas encore de synchronisation multi-appareils.
- Les comptes sociaux et les moteurs vidéo existants ne sont pas modifiés.
